# 智能农田房车 · 可编辑、可开合模型

本模型依据“房车建模参考_v2_一致性校对”在本机 Blender 5.2.1 中构建。原有 v1 简模与参考包均保留。主文件包含独立车身部件、内部家具、舱口机构、动画、相机、灯光，以及打包在文件中的 7 张参考图。

## 文件选择

- **智能农田房车_精细可开合_v2.blend**：继续建模、修改材质与编辑动画的主文件。
- **房车_独立开合动作.glb**：完整车辆，包含 3 个互不混合的动画片段，适合后续分别触发车顶舱、机器人舱与乘员门。
- **智能农田房车_精细可开合_v2.glb**：完整车辆，包含 1 个全车展开—收回的演示动画。
- **智能农田房车_精细可开合_v2.fbx**：供 Unity 等软件导入的几何与整体动画版本；已经重新导入 Blender 检查节点与动画存在，尚未在用户的 Unity 项目里测试。
- **房车开合演示.mp4**：实际 Blender 模型渲染的 6 秒演示，960×640、15 帧/秒。
- **renders**：关闭、展开、舱口近景、车内视角、剖视与开合中间状态的实际渲染图。PNG 为透明背景；视频为纯色背景。

## 在 Blender 里直接查看

打开主文件，在底部时间轴输入帧数或按空格播放：

| 帧数 | 状态 |
| --- | --- |
| 1–15 | 舱盖、机器人舱门、乘员门关闭，乘员梯收回 |
| 35 | 开启过程中的中间状态 |
| 55 | 车顶双舱盖打开，机器人舱门已形成坡道，乘员门与踏梯展开 |
| 75–100 | 无人机停机平台升起 |
| 115 | 停机平台先收回，其他舱门仍打开 |
| 160–180 | 舱门全部重新闭合 |

两片顶部舱盖有各自的铰链，侧舱门有真实铰接轴；支撑杆的运动已同步烘焙。侧舱仓库具有独立底板、顶板和隔墙，机器人朝向侧面出口。机器人坡道展开角为 125°，坡道端部接近地面。

## 独立控制

在“房车_独立开合动作.glb”中：

| 动画名称 | 控制范围 |
| --- | --- |
| Roof_OpenClose | 两片顶部舱盖、相应支撑杆、无人机升降平台 |
| RobotGarage_OpenClose | 侧部机器人舱门/坡道与支撑杆 |
| CrewEntry_OpenClose | 乘员门和踏梯 |

已经分别播放车顶舱和机器人舱动画进行回导检查：只播放车顶舱时机器人舱保持不动；只播放机器人舱时车顶舱保持不动；两者均能返回关闭状态。

Blender 主文件中的独立转轴名称及局部旋转范围：

| 转轴 | 局部轴 | 关闭 → 打开 |
| --- | --- | --- |
| CTRL_ROOF_FRONT | Y | 0° → 103° |
| CTRL_ROOF_REAR | Y | 0° → −103° |
| CTRL_ROBOT_RAMP | X | 0° → 125° |

手工编辑单个转轴后，原有动画会在切换帧时重新赋值；请在其动画关键帧上修改。支撑杆与升降平台已有配套动画，后续在 Unity 中优先播放完整的对应动画片段。若用代码直接设置角度，需同时更新支撑杆端点，不能只转舱盖而把支撑杆留在原位。

## 结构与编辑

模型前方为 +X、机器人舱所在侧为 −Y、上方为 +Z，单位为米。主体约 9.5 米长，主舱名义宽度约 2.5 米，含后视镜约 3.2 米宽，含天线约 4.66 米高。尺寸是为展示模型统一比例作出的设计取值。

对象按底盘、六轮、驾驶室、主舱墙体、固定车顶、车顶机构、机器人仓库、乘员入口、室内、外部五金、无人机、履带机器人分别归入集合。控制台、两把操作椅、三块屏幕、水槽操作台、储物箱和电气柜均为真实独立几何。

查看车内时，可以隐藏 `04_Habitat_Walls`、`05_Roof_Static`、`06_Roof_Hatches`、`10_Exterior_Hardware` 和 `11_Drone`。这是编辑时的剖视方式，车壳并非透明材质。完整车内也设置了 `CAM_Cabin_Looking_Rear` 和 `CAM_Interior_Looking_Front` 两个相机。

## 还原程度与后续使用

主外形、白蓝配色、三轴六轮、舱室布局和两处开合机构已按最新参考包搭建。车头曲面、细小机械构件、真实污渍磨损，以及舱内无人机和机器人仍有简化；这份文件是可编辑的展示/游戏模型，不能称为照片逐细节的完美复刻。

Blender 中的程序化微表面纹理保留在主文件里；GLB/FBX 主要保留基础材质属性。导入 Unity 后，可按项目渲染管线调整材质，并另行配置交互、碰撞体与导航。当前交付不包含车辆驾驶、无人机飞行或机器人行走的游戏逻辑。

本次采用 Aholo Lux3D 技能规定的本机 Blender 建模、组装、动画与直接文件交付路线。Lux3D 云端依赖初始化未就绪；没有提交云端生成任务，也没有消耗云端生成点数。
