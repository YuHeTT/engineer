# 巡航"点不动 / 进度归零"的两个根因（已修）

> 日期：2026-10-15
> 你反馈：① 点击巡航时直接返回上个页面，看不到巡航 ② 重新点机器人检测，进度又变成 0

---

## 一、根因（两个，都是我上一轮引入的）

### 根因 A：`FarmGrowthBinder` 把巡航**当场打死** ← 解释"看不到巡航情况"

我在上一轮加"亩数变化自动重排田块"时，在 `ApplyLandArea()` 里写了：

```csharp
var cruise = FindObjectOfType<FarmCruiseController>();
if (cruise != null) cruise.ResetToStart();   // ★ 这一行有问题
```

而 `ResetToStart()` 会 **`mode = CruiseMode.Idle`**。调用链是：

```
点「手动巡航」
  → StartManual()（mode = Manual）✅
  → Flow.GoTo(FarmStage) 切到农场 ✅
  → FarmGrowthBinder 检测到"刚开始模拟" → ApplyLandArea()
  → cruise.ResetToStart() → **mode 被打回 Idle**
  → 巡航当场结束，车不动了 ❌
```

**所以"看不到巡航情况"不是页面返错了，而是巡航一启动就被关掉了。**

**修法**：田块尺寸变化时只需要把小车**夹回田内**，不能重置模式与覆盖率 ——
新增 `FarmCruiseController.ClampInsideField()`，`ApplyLandArea()` 改调它。

### 根因 B：`OnEnter` 里重置了覆盖率 ← 解释"进度又变成 0"

我上一轮在 `RobotCruiseScreen.OnEnter` 里加了 `cruise.ResetToStart()`，
初衷是"每次进界面都从干净状态开始"。但这带来两个副作用：

| 副作用 | 现象 |
|---|---|
| 每次进/出本屏都清零覆盖率 | **来回切页面就丢进度**（你说的"进度又变成 0"）|
| 如果此刻巡航正进行，Mode 会被打回 Idle | 巡航被中断 |

**修法**：`OnEnter` 只做"解除按钮禁用"，**不再重置**。
真正的重置放在玩家**主动点击**「手动/自动巡航」的时候 ——
那时重置是符合直觉的（点了就是"重新开始一次探测"）。

---

## 二、为什么"点击巡航返回上个页面"这个描述容易误判

我查了巡航屏的按钮接线，**没有问题**：

```
RobotCruiseScreen.actions:
    Button_BackToFarm        Back
```

另外三个按钮（手动/自动/更新）走的是脚本里的 `OnClick`，这是设计如此。

所以你看到的现象，本质是**根因 A**：点完巡航后 `GoTo(FarmStage)` 切回农场，
但巡航立刻被 `ResetToStart()` 结束，**看起来就像"什么都没发生、回到了上个页面"**。

## 三、这轮还加了详细日志（一次就能定位）

因为"按钮点了没反应"这类问题光看现象很难判断，我加了 `LogCruiseStart()`。
点「手动巡航」或「自动巡航」时会打印：

```
[巡航] 点击「手动巡航」：当前界面状态=RobotCruise　cruise.Mode=Idle
       grid 覆盖率=0.0%　probe 覆盖率=0.0%
  switchToFarmOnCruise=True　目标状态=FarmStage(6)
  → 如果下面没有「[UI] → 农场主界面」，说明 GoTo 被拦住了。
[巡航] StartManual 完成，mode=Manual
[UI] → 农场主界面
```

**这一份日志能一次性区分三种情况**：

| 现象 | 说明 |
|---|---|
| 有 `[巡航] 点击…` 但没有 `StartManual 完成` | 卡在 `ResetToStart()` 里 |
| 有 `StartManual 完成` 但没有 `[UI] → 农场主界面` | `GoTo` 被拦（状态相同 / screens 未注册）|
| 三行都有，但车不动 | 是 `FarmGrowthBinder` 把 mode 打回去了（本轮修的就是这个）|

## 四、本轮改动

| 文件 | 改动 |
|---|---|
| `FarmCruiseController.cs` | 新增 `ClampInsideField()` —— 只挪小车、不动 Mode/覆盖率 |
| `FarmGrowthBinder.cs` | `ApplyLandArea()` 里 `ResetToStart()` → **`ClampInsideField()`** |
| `RobotCruiseScreen.cs` | `OnEnter` 去掉 `ResetToStart()`（只解禁按钮）；新增 `LogCruiseStart()` 详细日志 |

五个程序集编译通过。

## 五、请验证（3 步）

```
① 进农场 → 点「巡航」→ 点「手动巡航」
     ✓ Console 应该出现 [巡航] 点击「手动巡航」… + StartManual 完成，mode=Manual + [UI] → 农场主界面
     ✓ 画面切到农场，小车可以 Q/E 转向、W/S 前进
     ✓ 覆盖率随小车移动而上涨

② 回巡航界面 → 再进农场
     ✓ 覆盖率**不应该**被清零（这是本轮修的根因 B）

③ 点「自动巡航」
     ✓ 小车自己走，HUD 显示「自动巡航中 xx%　剩余约 n 秒」
     ✓ 覆盖率到 80% 后「更新数据」可点
```

**把 ① 的 Console 三行发我** —— 如果 `mode=Manual` 之后车还是不动，
那就说明还有第三处把 mode 打回去了，我可以顺着日志继续定位。

## 六、我的反思

这两个 bug 都是**我上一轮"修 bug"时引入的新 bug**：

| 上一轮我做的 | 引入的问题 |
|---|---|
| 加"亩数变化自动重排田块" | 顺手写了 `cruise.ResetToStart()` → **打死正在进行的巡航** |
| 在 `OnEnter` 加 `ResetToStart()` 想"给个干净状态" | → **来回切页面丢进度** |

共同点是：**我调 `ResetToStart()` 时没有检查"此刻巡航是否正在进行"**。
正确做法应该是：重置只在"玩家明确要求重新开始"时发生，
其它地方（尺寸变化、进出界面）只做**最小必要的修正**。

这一条我已经写进代码注释（`ClampInsideField` 与 `OnEnter` 两处），避免以后再犯。
