## Unity 中的验收步骤

1. 若 Unity 已经打开 UI 场景，请先停止 Play，再重新从磁盘加载 `Assets/Scenes/UI.unity`。不要把编辑器缓存中的旧版本保存覆盖本轮场景改动；如有自己的未保存改动，先另存副本再合并。
2. 土地页输入 4 亩，pH 6.2，其余输入有效值；尝试空白、abc、NaN、0 亩，应该停在本页并提示；改回有效值，进入确认页核对新值。
3. 开始巡航，观察房车动画。若 Console 提示没有片段，检查房车 prefab 的 Animation/Animator 与导入的动画片段；Animator 状态名必须与 PlayClip 使用的名字一致。开、合若是两个独立片段，后续分别指定片段和状态，不要默认第一个片段代表完整双向动作。
4. 分析页输入错误数字或负数，应不换阶段；改成有效水肥，提交一次只推进一阶段。跑完四次，收益页显示四阶段结果、静态指标、单位面积产量、总产量与全田累计投入；重新开始后不保留上一局投入。
5. 重点检查新增累计投入一行是否在公式区完整显示。溢出时增加 Result/Formula 区高度或减小公式字号；本轮未在 Play 中测量布局。
