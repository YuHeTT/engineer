## 二、"巡航灰色"的三个可能来源（已全部修掉）

你说"田地还在，但就是灰色"——这排除了"没渲染"，所以是**有东西盖在上面或相机位置不对**。
我找到三处，都修了：

### 来源 A：小车模型太大，相机贴进了模型内部 ★ 最可能

我实测了 `reference_rover_lux3d_wheels.fbx`：

```
9.195 × 7.011 × 2.790 m
```

**而一整个田块才 12 × 9 m。** 这台车几乎和一块田一样大 ——
相机跟随时（后撤 6~11 m）会**贴在模型表面上或钻进模型内部**，
渲染出来就是一片纯色（模型材质的灰白色/内部面）。

**修法**：新增 `roverScale`（默认 **0.25**）—— 把车缩到约 2.3 m 长，
和一株玉米（1.95 m）相称。

### 来源 B：未覆盖遮罩 alpha 太高（0.38）

深蓝灰 0.38 alpha 铺满整片田 —— 远看就是"田变灰了"。

**修法**：alpha **0.38 → 0.15**（能看出范围，又不挡田地）。

### 来源 C：遮罩在"没巡航"时就盖上

`FarmFieldGrid.RefreshMask()` 原来只要不在编辑期就显示遮罩，
于是**一进农场就是一片灰**。

**修法**：新增 `cruiseActive` 门控 —— **只有点了巡航才显示遮罩，巡航结束就撤掉**。

### 来源 D：相机跟车参数与小车尺寸不匹配

原来跟车是"高 9 m + 后撤 11 m"，而俯视模式的距离是按"看全一个田块"算的。
两者混在一起会导致相机位置很怪。

**修法**：跟车改用**固定俯角**（`cruiseFollowPitch` 默认 32°）+ 按
`cruiseFollowHeight(4.5)` 与 `cruiseFollowBack(6)` 算出的总距离。

## 三、手动巡航操控：审查结果

我把 `UpdateManual()` 整段逐行看了一遍。**逻辑本身是对的**，但有三个**手感问题**：

| # | 问题 | 影响 | 修法 |
|---|---|---|---|
| 1 | **相机和小车抢 WASD/QE** | 按 W 时相机也被推走 → 车动但画面乱、看不清 | 巡航期间相机**完全不接收键盘**（上轮已修） |
| 2 | **小车太大** | 相机贴进模型 → 画面纯色，**看起来像"车没动"** | `roverScale = 0.25` |
| 3 | **没有速度反馈** | 按 W 有没有生效无法判断 | 每 0.5 秒打一条"位置/朝向/速度"日志（见下） |

### 现在的手动操控

```
Q / E  或  左/右方向键   →  转向（150 度/秒）
W / S  或  上/下方向键   →  前进 / 后退（8 米/秒）
```

**没有 `A/D` 横移**（上一轮已改成车式操控）——因为"横移 + 强制转向对齐"
会让车转着圈跑，这是之前"键位操作问题很大"的原因。

## 六、关于"每阶段重新巡航"（已按你确认的实现）

`FarmGrowthBinder` 检测到 UI 阶段变化时：

```csharp
grid.ClearCoverage();     // 覆盖率归零
grid.EndCruise();         // 撤掉遮罩，等玩家重新开始
probe.Reset();            // 探测数据一并清空
```

Console（开 `logSync` 时）会打印：
```
[农场] 进入 S2，巡航覆盖率与探测数据已清零（每阶段需重新探测）。
```

这样每个生育期都要重新下地探测，符合"数字孪生"的设定。
