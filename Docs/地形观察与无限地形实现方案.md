# 地形观察页与「无限地形」实现方案

> ⚠️ **2026-10-31 状态**：本轮已把程序化地形实现（`Assets/Scripts/UI/Terrain`、`Terrain_Plain.unity`、地形 Shader、画板工具）暂时删除，改为先用 Unity Terrain 刷出一片地形。本文保留作设计参考；UI 观察页壳（`LandPreviewScreen` 等）保留。
>
> 日期：2026-10-31
> 适用：engineer / Unity 2022.3.62f2c1
> 回答的问题：土地类型点「选择」后，如何把玩家放进一个**看不到边、有真实起伏**的对应地形里观察，再点「构建农场」进入 Farm 场景。

---

## 0. 结论先行

1. **现有 4 个地形模型不能拼成无限地形。** 它们是 6 m × 6 m、带 2~3.7 m 土壤剖面的「地块模型 / diorama」，不是可平铺的地形贴片；边缘高度差最大约 13 cm，每 6 m 还会露出一圈垂直土壁。
2. **正确做法是「高度场 + 分块网格」**：写一个连续的 `Height(x, z)` 函数，按土地类型调参；网格、相机、石头、水面、农场平台**全部采样同一个函数**。现有 glb 只做出生点的剖面地标、远景剪影和配色参考，不用来铺地。
3. **观察页不需要真的无限。** 玩家只会看十几秒到几分钟，**500 m 左右的地形 + 雾 + 远景环**就足够「看不到边」。先做单块 512 m 的静态高度场（1~2 天能跑），确认观感后再换成分块流式（真正能一直飞）。
4. **Unity 地形刷不是关键**。刷子只是编辑工具；真正的问题是这四个模型不是高度图、不能无缝拼接。转成 TerrainLayer 反而更麻烦（没有贴图、没有 splat）。

## 1. 先看清素材：截图里的「土地」不是模型

`Assets/可能用到的建模/土地/` 里实际只有：

```
01-平川台.png / 02-泽洼域.png / 03-崇岭阶.png / 04-高原坪.png   ← 1536×1024 预览图
平川台-建模预览.png / 泽洼域-建模预览.png / ...                 ← 1000×1000 三视角预览
Materials/01-平川台.mat                                        ← 把上面某张预览图当 _MainTex 的占位材质
```

**这个目录里没有 .glb。** 真正的模型在：

```
Assets/Art/Models/Terrain/平川台.glb / 泽洼域.glb / 崇岭阶.glb / 高原坪.glb
Assets/Art/Models/TerrainPlus/01_干燥起伏土壤.glb / 02_积水草地.glb / ...
```

### 1.1 实测规格

用 glTF 解析器逐块量出来的数据：

| 模型 | 尺寸 X×Z×Y (m) | 三角面 | 顶面网格 | 材质情况 |
|---|---:|---:|---:|---|
| 平川台 | 6 × 6 × 2.00 | 12,606 | 144 × 144 | 4 个材质中 3 个**没有颜色** |
| 泽洼域 | 6 × 6 × 2.00 | 12,320 | — | 6 个中 3 个没有颜色 |
| 崇岭阶 | 6 × 6 × 3.74 | 21,290 | — | 4 个中 3 个没有颜色 |
| 高原坪 | 6 × 6 × 3.42 | 13,406 | — | 4 个中 3 个没有颜色 |
| TerrainPlus 01~04 | 5.15 × 5.15 × 1.76~2.83 | 17,278~21,732 | — | **全部带 baseColor** |

平川台顶面四个边的实测高度：

```
x = -3 : 0.773 ~ 0.838
x = +3 : 0.722 ~ 0.799
z = -3 : 0.750 ~ 0.843
z = +3 : 0.756 ~ 0.849
顶面整体 : 0.716 ~ 0.850
```

也就是说：**相邻两块拼在一起，接缝处会有最多约 13 cm 的台阶**；而且每块模型四周都带从 y = −1 开始的土壤剖面（2~3.7 m 高）。拼起来后，相邻土壁会重叠、Z-fighting，外圈则直接露出 2~3.7 m 的垂直土壁。

### 1.2 为什么「铺」不出来

| 观察距离 | 需要的 6 m 地块数 | 三角面 |
|---:|---:|---:|
| 100 m × 100 m | ≈ 278 块 | ≈ 350 万 |
| 200 m × 200 m | ≈ 1,111 块 | ≈ 1,400 万 |
| 500 m × 500 m | ≈ 6,944 块 | ≈ 8,750 万 |

一个 1080p / 60fps 的演示场景，地形控制在 **20~50 万三角面**比较稳。也就是说，连 100 m 见方都比预算高 7 倍；再加上接缝和土壁，拼模型这条路在「无限」目标下没有可行性。

> 补充：Unity 的 Terrain 组件**可以在运行时用代码生成 TerrainData**，并不是只能手刷。但那需要 TerrainLayer / splatmap / 贴图，而现有素材没有这些；6 m 的模型也不是高度图。自己生成网格反而更直接、更可控、更符合现在的低多边形平涂画风。

### 1.3 一个必须提前处理的材质坑

`平川台.glb` 的 3 个地表材质在 glTF 里既没有 `baseColorFactor`，也没有贴图，也没有顶点色 `COLOR_0`。按 glTF 规范，它们会按**白色**处理。你截图里看到的棕色是 Blender 渲染的预览图，不是 glb 里的材质。

**建议**：先把这个 glb 拖进空场景确认一下；如果确实是白模，就：
- 新地形**完全不用它的材质**，用我们自己的调色板；
- 如果要在出生点摆一块剖面地标，按材质名（`Fertile plain surface` / `Thick plain topsoil` / `Plain sandy subsoil` / `Plain stones`）逐个赋颜色；
- 需要颜色参考时看 `TerrainPlus`，它的材质是带颜色的。

`Materials/01-平川台.mat` 也不用抱期望：它的 `_MainTex` 指向的是 `01-平川台.png`（1536×1024 的成品渲染图），不是可平铺的地表贴图。

## 2. 正确做法：高度场 + 分块网格

### 2.1 一句话架构

```
GameContext.LandTypeId
        │
        ▼
LandTerrainProfile（4 套参数：振幅 / 波长 / 台地 / 水位 / 颜色）
        │
        ▼
TerrainHeightField.Sample(x, z)   ← 唯一权威高度
        ├── TerrainPatchBuilder    单块大网格 / 分块 LOD
        ├── TerrainFlyCamera       出生点、贴地限制
        ├── TerrainScatter         石头 / 草按高度落位
        ├── TerrainWater           泽洼域水面
        └── FarmPad                构建农场时压平
```

**铁律：任何地方都不许自己算高度，一律调 `Sample(x,z)`。** 只要相机、网格、石头、农场平台各自算各自的，就一定会出现「相机钻进地里 / 石头浮空 / 农场边缘悬空」这类问题。

### 2.2 「无限」到底怎么定义

真正的无限几何不存在，工程上都是**移动窗口**：

```
相机每走到一个新位置
  → 只保留半径 R 内的分块
  → 远处回收，近处生成
  → 雾 + 远景环把边界藏掉
  → 走 2 km 后整体平移一次原点（floating origin），避免浮点精度抖动
```

对观察页来说，R = 250~400 m、雾在 300~500 m 完全吃掉边界，玩家是感知不到「有限」的。

## 3. 四种地形的高度场配方

目标不是「四种不同颜色的噪声山」，而是把四个 6 m 模型的**造型语言**翻译成参数：

| 类型 | 基础高度 | 大起伏 | 中起伏 | 特征函数 | 水面 | 主色 |
|---|---:|---|---|---|---|---|
| 平川台 | 0 m | 9 m / 540 m | 2.6 m / 130 m | 缓坡 + 浅干沟 | 无 | 土黄 #8C7864 / #786450 |
| 泽洼域 | −3 m | 2.5 m / 500 m | 1.5 m / 100 m | 盆地掩码，中心下凹 5 m | −1.8 m | 湿土 #4A3A26 / 水 #4F7A80 |
| 崇岭阶 | 10 m | 25 m / 800 m（脊状） | 6 m / 160 m | 3 m 一级台地，边缘陡坎 | 无 | 黄土 #B08A5A / 崖 #8A5A32 |
| 高原坪 | 22 m | 台顶 26 m / 掩码 650 m | 2 m / 180 m | 高原掩码 + 25 m 陡崖带 | 无 | 高原土 #B48C78 / 崖 #64503C |

### 3.1 通用公式

```csharp
float H(float x, float z)
{
    // 1) 域扭曲：让噪声的等高线不那么「圆」
    Vector2 p = new Vector2(x, z) + seedOffset;
    p += new Vector2(Fbm(p.x * 0.0011f, p.y * 0.0011f, 2) - 0.5f,
                     Fbm(p.x * 0.0013f + 17.3f, p.y * 0.0013f - 9.1f, 2) - 0.5f) * warp; // 40~80 m

    // 2) 三层噪声
    float h = baseHeight;
    h += macroAmp  * SignedFbm(p.x / macroScale,  p.y / macroScale,  3);
    h += midAmp    * SignedFbm(p.x / midScale + 31.7f, p.y / midScale - 12.3f, 3);
    h += detailAmp * SignedFbm(p.x / detailScale, p.y / detailScale, 2);

    // 3) 类型特征
    switch (kind)
    {
        case Kind.Wetland:  h = ApplyBasin(h, p);   break;
        case Kind.Ridge:    h = ApplyTerrace(h, p); break;
        case Kind.Plateau:  h = ApplyPlateau(h, p); break;
    }

    // 4) 农场平台（如果有）
    h = FlattenForFarm(h, x, z);

    return h;
}
```

`SignedFbm` 就是 `(Fbm(...) - 0.5f) * 2f`，把 Perlin 的 0~1 映射到 −1~1。

### 3.2 三个特征函数

**台地（崇岭阶）**：把高度量化到 3 m 一级，但保留 25% 的斜坡过渡，避免出现「完美楼梯」：

```csharp
float ApplyTerrace(float h, Vector2 p)
{
    float t = h / step;                 // step = 3 m
    float f = Mathf.Floor(t);
    float frac = t - f;
    float riser = Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(0.72f, 1f, frac));
    float stepped = (f + riser) * step;
    return Mathf.Lerp(h, stepped, terraceAmount); // 0.7~0.8
}
```

**高原（高原坪）**：用低频掩码决定「台顶 / 崖下」，中间用 25 m 的过渡带做出断崖：

```csharp
float ApplyPlateau(float h, Vector2 p)
{
    float m = Fbm(p.x / 650f, p.y / 650f, 3);
    float top = Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(0.42f, 0.58f, m));
    float cliffNoise = SignedFbm(p.x / 45f, p.y / 45f, 2) * 2.5f;
    return Mathf.Lerp(lowHeight + h * 0.25f, highHeight + h * 0.15f, top) + cliffNoise * (1f - top);
}
```

**盆地（泽洼域）**：低频掩码往下挖，水面是一个独立的水平面：

```csharp
float ApplyBasin(float h, Vector2 p)
{
    float b = Fbm(p.x / 320f + 7.1f, p.y / 320f - 3.9f, 2);
    float basin = Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(0.55f, 0.82f, b));
    return h - basin * 5f;
}
```

> 泽洼域的水面不要跟着地形起伏，它是一个全局 `waterLevel` 的平面；地形低于水面的部分自然被水盖住，再在近岸把顶点色压暗做出湿泥。

### 3.3 参数怎么调

- **平川台**：`macroAmp` 调到 9~10 m、`macroScale` 520~550 m，再加一条 2~3 m 深的浅干沟；站在 13 m 高度能明显看出地势，但仍保持缓坡。
- **泽洼域**：盆地掩码的频率要低（300~500 m 一个洼），否则会变成「一片小水坑」。
- **崇岭阶**：脊状噪声 `ridged = 1 - |2n - 1|` 比普通 fBm 更像山脊；台地宽度由 `step` 和坡度共同决定。
- **高原坪**：台顶要**真的平**（细节振幅 ≤ 0.6 m），否则「高原」会变成「高山」。

### 3.4 确定性

- 每套地形用固定 `seed`（例如 `Hash32(landTypeId)`），同一块地每次进入长得一样。
- **不要按 chunk 加随机偏移**，否则接缝处高度对不上。
- `Mathf.PerlinNoise` 是确定性的，可以先用于 MVP；以后要上 Burst/Job，再换成自定义 hash 噪声。

## 4. 网格：先静态大块，再流式

### 4.1 第一版（推荐先做）：一块 512 m 的静态高度场

> 已按这一版落地一个独立测试场景：`Assets/Scenes/Terrain_Plain.unity`，打开直接 Play 即可飞行观察平川台；说明见 [平川台地形观察测试场景.md](平川台地形观察测试场景.md)。
> 测试场景支持**编辑模式调参**：选中 `TerrainPlainBootstrap`，或菜单 **Tools ▸ 地形 ▸ 打开平川台调参**，改 Inspector 里的 `profile` 参数即可在 Scene 视图实时重建临时地形；预览对象带 `DontSave`，不会写进场景。

| 项 | 建议值 |
|---|---|
| 范围 | 512 m × 512 m |
| 顶点间距 | 2 m（257 × 257 = 66,049 顶点） |
| 三角面 | ≈ 131,000 |
| 索引格式 | `IndexFormat.UInt32`（顶点数已超过 65,535） |
| 相机活动范围 | 中心 ±240 m |
| 雾 | 指数平方，密度 0.0022，远端 550 m |
| 生成时机 | 进入观察页时协程生成，0.2~0.5 s |

这个规模对桌面演示完全够：玩家在 240 m 范围内飞，雾在 400 m 外把边界吃掉，看起来就是「看不到边」。**先把这个跑通，再谈流式。**

如果不想处理 32 位索引，可以拆成 4 块 256 m × 256 m（每块 129 × 129 顶点），或者做 3 层同心环：

```
内环 128 m，1 m 间距   → 近处细节
中环 256 m，2 m 间距   → 主体
外环 512 m，4 m 间距   → 远景
```

### 4.2 第二版：分块流式 + LOD

| 项 | 建议值 |
|---|---|
| 分块 | 64 m × 64 m |
| LOD0 / 1 / 2 | 65² / 33² / 17² 顶点（1 m / 2 m / 4 m） |
| 可见半径 | 320 m（5 × 5 块） |
| 每帧生成预算 | 1~2 块 |
| 接缝 | 每块四周加一圈向下 2 m 的 skirt，遮住 LOD 裂缝 |
| 碰撞 | 观察页不需要 MeshCollider，相机用 `Height()` 贴地即可 |
| 浮动原点 | 相机累计位移 > 2 km 时整体平移，避免浮点抖动 |

生成一块 65² 的网格大约 1~2 ms；25 块分摊到 25 帧，进入观察页时用加载页盖住即可。

### 4.3 法线与顶点色

不要用 `Mesh.RecalculateNormals()`（每次生成都多一遍遍历），直接从高度网格算中心差分：

```csharp
// heights 是 (res+1)² 的数组
float hl = heights[z, x - 1], hr = heights[z, x + 1];
float hd = heights[z - 1, x], hu = heights[z + 1, x];
Vector3 n = new Vector3(hl - hr, 2f * step, hd - hu).normalized;
```

顶点色同时算好：

```csharp
float slope = Vector3.Angle(n, Vector3.up);
Color c = Color.Lerp(soilColor, grassColor, grassMask);
if (slope > 32f) c = Color.Lerp(c, rockColor, Mathf.InverseLerp(32f, 55f, slope));
if (waterLevel > -100f && y < waterLevel + 1.2f) c = Color.Lerp(c, mudColor, 0.6f);
c *= 0.95f + 0.1f * Hash01(x, z); // 轻微色差，破掉大色块
```

## 5. 材质、配色与「像真的」

### 5.1 顶点色 + 一个 Surface Shader

现有 glb 是平涂低多边形风格，没有贴图。最匹配、最省事的方案是**顶点色**：

```shader
Shader "Engineer/TerrainVertexColor"
{
    Properties { _Smoothness ("Smoothness", Range(0,1)) = 0.1 }
    SubShader
    {
        Tags { "RenderType"="Opaque" }
        LOD 200
        CGPROGRAM
        #pragma surface surf Standard fullforwardshadows
        #pragma target 3.0
        struct Input { float4 color : COLOR; float3 worldNormal; };
        half _Smoothness;
        void surf (Input IN, inout SurfaceOutputStandard o)
        {
            o.Albedo = IN.color.rgb;
            o.Metallic = 0;
            o.Smoothness = _Smoothness;
            o.Normal = normalize(IN.worldNormal);
        }
        ENDCG
    }
    FallBack "Diffuse"
}
```

- 不用 UV，所以没有贴图接缝。
- 想再加细节，可以在 shader 里叠一层世界坐标噪声，或加一张 256×256 的可平铺噪声图。
- 地形**不投阴影**（`ShadowCastingMode.Off`）、只接收阴影；太阳阴影留给玉米、房车、石头。
- 内置管线用 Surface Shader；如果以后换 URP，这段要改写成 HLSL。

### 5.2 配色

从预览图取的主色（可按实际观感微调）：

| 类型 | 地表 | 草/植被 | 岩/崖 | 水 |
|---|---|---|---|---|
| 平川台 | `#8C7864` | `#7E7A52` | `#6B5A45` | — |
| 泽洼域 | `#4A3A26` | `#58662E` | `#3A3328` | `#4F7A80` (α 0.75) |
| 崇岭阶 | `#B08A5A` | `#8A7A48` | `#8A5A32` | — |
| 高原坪 | `#B48C78` | `#8C7A58` | `#64503C` | — |

### 5.3 氛围

- 天空：继续用 `Assets/Art/Skybox/sky-7.mat`。
- 雾：`FogMode.ExponentialSquared`，密度 0.0022，颜色取地平线色；这是藏边界的**主要手段**。
- 远景：如果雾不够，加一圈 300~1200 m 的低模「地平线环」，只采样大起伏，颜色接近雾。
- 水面（仅泽洼域）：一个 `waterLevel` 的平面，半透明 + 菲涅尔；不要做复杂反射。
- 点缀：用 GPU Instancing 在 60 m 内撒 200~500 块石头/草簇；按 `Height()` 落位，确定性随机。

### 5.4 现有 glb 怎么用

**不要铺地，但当「地标」很好用**：

- 出生点旁边放 1 块 1.5~2 倍大小的本地块，半埋进山坡，露出**土壤剖面**——这正好是模型最好看的部分，也给玩家一个「这块地有多厚」的直观参照。
- 远景把它放大 3~5 倍当山体剪影。
- 记得按材质名赋颜色（见 1.3）。

**可选进阶：把顶面烘焙成 6 m 细节印章。** 平川台的顶面是 144×144 的雕刻网格，可以离线烘成一张 144×144 的高度图，在 `Height()` 里以 6 m 为周期镜像平铺，只影响近处 40 m 的微起伏。这样既保留了美术雕过的细节，又不会出现接缝。**第一版不做**，等主体跑通再考虑。

## 6. 相机与交互

### 6.1 飞行相机

`TerrainFlyCamera`：

```
右键拖拽 / 按住右键   → 转视角（不要用锁定鼠标，否则 UI 点不到）
W A S D               → 前后左右（相对视角，水平）
Q / E                 → 下降 / 上升
Shift                 → 加速
滚轮                  → 调基础速度
```

- 高度限制：`y = Mathf.Max(y, Height(x,z) + 1.8f)`，防止钻进地形。
- 速度建议 8~30 m/s；观察页不需要战斗机速度。
- 进入时给一个 3~5 秒的缓慢自动漂移/环绕，玩家一按键就停，画面更「展示」。
- 退出时恢复相机原来的位置/旋转（保存 `Transform` 快照）。

### 6.2 和现有农场相机的关系

**不要只调 `FarmCameraRig.SetInputEnabled(false)`。** 它的 `LateUpdate` 即使不读输入，仍然会 `SmoothDamp` 到 `ComputePosition()`，会和飞行相机抢 Transform。

正确做法：


- 「构建农场」= 淡出预览 → 生成/恢复农场周边地形（可选）→ 相机瞬移回农场 → 淡入。
- 加载动画把瞬移完全盖住，玩家感知就是「建好了，到了农场」。
- 农场的 `FarmCameraRig` 保持原来的俯视 20° / 高度 22 / 距离 14，`SetViewLevel(Medium)`，视角和现在一致。

**第二版（更连贯，但要多测）：农场真的坐落在同一片地形里。**

- 在 `Height()` 里加一个农场平台：

```csharp
float FlattenForFarm(float h, float x, float z)
{
    float d = Vector2.Distance(new Vector2(x, z), farmCenter);
    float w = Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(farmRadius, farmRadius + blend, d));
    return Mathf.Lerp(farmHeight, h, w);
}
```

建议 `farmRadius = 45 m`、`blend = 25 m`、`farmHeight = -0.2 m`。
- 关掉 `FarmTerrainRing` 和农场自带的 `TerrainPad`（否则会和程序化地面打架），让农场土壤块直接坐在程序化地面上。
- 农场周边 256 m 的地形在加载时生成，超出部分用雾。
- 这样「构建农场」就是**在选中的地形里压平一块地、把农场放上去**，叙事最完整。代价是要处理 `FarmFieldBuilder` / 路径 / 房车的落地高度。

## 10. 风险与待拍板

### 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| **地形 glb 是白模** | 3/4 材质无颜色 | 先验证；新地形用自己的调色板；地标按材质名赋色 |
| **枚举插入导致场景错位** | `state` 是 int 序列化 | 只追加 `LandPreview = 10` |
| **相机抢 Transform** | `FarmCameraRig.LateUpdate` 一直在动 | 预览时 `enabled = false`，不是只关输入 |
| **接缝 / LOD 裂缝** | 不同 LOD 的 T 型接缝 | 每块加 skirt；同 LOD 共享高度采样 |
| **32 位索引** | 257² > 65,535 | `IndexFormat.UInt32`，或拆块 |
| **农场地面打架** | `FarmTerrainRing` / `TerrainPad` 与程序化地面重叠 | 第二版里关掉它们 |
| **雾/天空两套** | 预览和农场的 RenderSettings 不同 | 进入前快照、退出恢复 |
| **GC 卡顿** | 每帧 new 数组/网格 | 复用 `Mesh`/`List`，按帧预算生成 |

## 附录 A：最小高度场代码骨架

```csharp
using UnityEngine;

namespace Engineer.UI
{
    public enum LandKind { Plain = 0, Wetland = 1, Ridge = 2, Plateau = 3 }

    [System.Serializable]
    public class LandTerrainProfile
    {
        public LandKind kind;
        public string id;
        public string displayName;
        [TextArea] public string intro;

        public float baseHeight;
        public float macroAmp = 5f, macroScale = 700f;
        public float midAmp = 1.2f, midScale = 120f;
        public float detailAmp = 0.12f, detailScale = 14f;
        public float warp = 50f;

        public float terraceStep = 3f;
        [Range(0f, 1f)] public float terraceAmount = 0.75f;
        public float basinDepth = 5f;
        public float waterLevel = -1000f;

        public Color soilColor, grassColor, rockColor, mudColor;
        public Vector3 spawnPosition;
        public float spawnYaw, spawnPitch;

        public int seed;
    }

    public class TerrainHeightField
    {
        private readonly LandTerrainProfile p;
        private readonly Vector2 offset;

        public TerrainHeightField(LandTerrainProfile profile)
        {
            p = profile;
            var r = new System.Random(profile.seed);
            offset = new Vector2(r.Next(-5000, 5000), r.Next(-5000, 5000));
        }

        public float Sample(float x, float z)
        {
            var q = new Vector2(x, z) + offset;
            q += new Vector2(Fbm(q.x * 0.0011f, q.y * 0.0011f, 2) - 0.5f,
                             Fbm(q.x * 0.0013f + 17.3f, q.y * 0.0013f - 9.1f, 2) - 0.5f) * p.warp;

            float h = p.baseHeight
                    + p.macroAmp * SignedFbm(q.x / p.macroScale, q.y / p.macroScale, 3)
                    + p.midAmp * SignedFbm(q.x / p.midScale + 31.7f, q.y / p.midScale - 12.3f, 3)
                    + p.detailAmp * SignedFbm(q.x / p.detailScale, q.y / p.detailScale, 2);

            switch (p.kind)
            {
                case LandKind.Wetland:
                    h -= Basin(q) * p.basinDepth;
                    break;
                case LandKind.Ridge:
                    h = Terrace(h);
                    break;
                case LandKind.Plateau:
                    h = Plateau(h, q);
                    break;
            }

            return h;
        }

        private float Basin(Vector2 q)
        {
            float b = Fbm(q.x / 320f + 7.1f, q.y / 320f - 3.9f, 2);
            return Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(0.55f, 0.82f, b));
        }

        private float Terrace(float h)
        {
            float t = h / p.terraceStep;
            float f = Mathf.Floor(t);
            float frac = t - f;
            float riser = Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(0.72f, 1f, frac));
            return Mathf.Lerp(h, (f + riser) * p.terraceStep, p.terraceAmount);
        }

        private float Plateau(float h, Vector2 q)
        {
            float m = Fbm(q.x / 650f, q.y / 650f, 3);
            float top = Mathf.SmoothStep(0f, 1f, Mathf.InverseLerp(0.42f, 0.58f, m));
            float cliff = SignedFbm(q.x / 45f, q.y / 45f, 2) * 2.5f;
            return Mathf.Lerp(6f + h * 0.25f, 26f + h * 0.15f, top) + cliff * (1f - top);
        }

        public Vector3 Normal(float x, float z, float e = 1f)
        {
            float hl = Sample(x - e, z), hr = Sample(x + e, z);
            float hd = Sample(x, z - e), hu = Sample(x, z + e);
            return new Vector3(hl - hr, 2f * e, hd - hu).normalized;
        }

        private static float Fbm(float x, float y, int octaves)
        {
            float sum = 0f, amp = 0.5f, freq = 1f, norm = 0f;
            for (int i = 0; i < octaves; i++)
            {
                sum += Mathf.PerlinNoise(x * freq, y * freq) * amp;
                norm += amp;
                amp *= 0.5f;
                freq *= 2f;
            }
            return sum / norm;
        }

        private static float SignedFbm(float x, float y, int octaves)
        {
            return (Fbm(x, y, octaves) - 0.5f) * 2f;
        }
    }
}
```

> 注意：这段是骨架，`FlattenForFarm`、颜色、LOD、mesh 生成还没写；先用来把高度场调对。
