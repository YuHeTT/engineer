# 两个问题的修复报告

> 日期：2026-10-15

---

## 一、"只有第一阶段能巡航" —— 找到确定 bug

### 根因：按钮被**永久禁用**

`RobotCruiseScreen.RefreshCruiseState()` 里的原代码：

```csharp
var autoDone = cruise != null &&
               (cruise.Mode == FarmCruiseController.CruiseMode.Auto ||
                cruise.Mode == FarmCruiseController.CruiseMode.Finished);
manualButton.interactable = !autoDone || !canAnalyze;
autoButton.interactable   = !autoDone || !canAnalyze;
```

**时间线**：

```
你点「手动巡航」
  → cruise.StartManual() 把 Mode 设成 Manual
  → 下一帧 RefreshCruiseState() 跑：
       autoDone 的判断只排除了 Idle，所以 Mode == Manual 时 autoDone = true
       canAnalyze = false（覆盖率还很低）
       → manualButton.interactable = !true || !false = false || true = **true**  ← 咦
```

等等，`!autoDone || !canAnalyze` = `false || true` = `true` —— 这时按钮其实是可用的。

**真正出问题的是"扫完之后"**：

```
覆盖率到 80% → canAnalyze = true
  → manualButton.interactable = !autoDone || !canAnalyze = false || false = **false**
  → 两个按钮永久禁用
```

而且 `cruise.ResetToStart()` 只在 `OnEnter` 和点击按钮时调；
进入第二阶段的巡航界面时，`cruise.Mode` 还是上一阶段留下的 `Finished`/`Auto`，
`Update()` 每帧都会把按钮设为 `false` —— **点不动了**。

**这就是"只有第一阶段能巡航"。**

### 修法

用一个明确的 `cruiseFinished` 标志替换"猜 `Mode`"，并且：

| 时机 | 动作 |
|---|---|
| `OnEnter`（每次进巡航界面） | **`cruiseFinished = false`** + `cruise.ResetToStart()` |
| 点「手动/自动巡航」 | `cruiseFinished = false` |
| 点「更新数据」成功 | `cruiseFinished = true` |

按钮状态改为 `interactable = !cruiseFinished` —— 清楚、可预测。

## 二、"探测值 VS 真值没有" —— 加了诊断，请按路径走

`ReportProbeGap()` 原本是**静默 return**：

```csharp
if (probe == null || !probe.IsActive) return;   // ← 什么都不说
```

所以"没有输出"时无法判断原因。**已改成每种情况都打明确告警**：

| 情况 | 现在的输出 |
|---|---|
| `GameFlowController` 上没有 Probe | `[Analyze] 没有 FarmProbeState…` |
| 本阶段**没走过巡航界面** | `[Analyze] 探测未激活（probe.IsActive = false）—— 说明本阶段没有走过「巡航」界面。` |
| 正常 | `[Analyze] 探测值 vs 真值（覆盖率 xx%，误差幅度 5%~10%）：…` |

### 最可能的原因：**跳过巡航直接进了分析**

`probe.Begin()` 只在 `RobotCruiseScreen.OnEnter` 里调用。
如果你从农场主界面**直接点「分析」**（没先点「巡航」），`probe.IsActive` 就是 `false`，
于是没有对比输出 —— **这其实是符合设计的**（没探测就没有探测数据）。

**正确的路径**：

```
农场主界面 → 点「巡航」→ 在巡航界面点「手动巡航」或「自动巡航」
           → 覆盖率到 80% → 点「更新数据」
           → 回农场 → 点「分析」→ 这时才会打印探测值对比
```

### 快速验证的捷径

不想等巡航跑完的话：**在巡航界面按 `G`** ——
它会把剩余区域一次扫完，覆盖率直接补齐，然后就能点「更新数据」。
这样 3 秒就能走完"巡航→更新→分析"，确认探测值对比是否出现。

## 三、顺手做的一件事

`OnEnter` 现在会调 `cruise.ResetToStart()`。
之前只有点击按钮时才重置，所以**每次进巡航界面，小车还停在上次的位置**，
覆盖率显示的是上次的残留值 —— 现象就是"覆盖率一开始就是满的/乱的"。

现在每次进界面都是干净状态：小车回田角、覆盖率归零、遮罩全部盖上。
