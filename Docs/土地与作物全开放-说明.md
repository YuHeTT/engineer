# 土地类型 / 植物类型 2、3、4 开放说明

> 日期：2026-10-31
> 范围：土地类型选择、植物类型选择、确认页、数值内核的作物入口、农场白膜
> 地形部分本轮不处理。

---

## 1. 现在能选什么

### 土地类型（四块全开）

| 卡 | 显示名 | Id | 选择后 |
|---|---|---|---|
| 1 | 平川台 | `flat_plain` | 写入 `GameContext.LandTypeId/Name` → `LandParams` |
| 2 | 泽洼域 | `low_wetland` | 同上 |
| 3 | 崇岭阶 | `steep_ridge` | 同上 |
| 4 | 高原坪 | `plateau` | 同上 |

- `SimConfig.Terrains` 四套 `PlayableInV1 = true`。
- `GameContext` 默认 id 改成规范值 `flat_plain`（旧值 `pingchuantai` 仍被 UI 映射兼容）。
- 地形视觉暂时不接：四块地共用现有农场地面；等 Unity Terrain 刷好后再按 `LandTypeId` 换地形。
- 土地类型当前**不影响数值**（没有各类型独立的初始土壤区间/曲线）；先保证选择、确认页、收益页都能显示正确名称。

### 植物类型（四种全开）

| 卡 | 显示名 | Id | 选择后 |
|---|---|---|---|
| 1 | 玉米 | `corn` | 写入 `GameContext.PlantTypeId/Name` → `Confirm` |
| 2 | 甜菜 | `beet` | 同上 |
| 3 | 红薯 | `sweet_potato` | 同上 |
| 4 | 土豆 | `potato` | 同上 |

- `SimConfig.Crops` 四种 `PlayableInV1 = true`。
- 作物选择会**重新启动一次数值内核**：`LandParams` 阶段启动时还没选作物，所以 PlantSelect 选完作物后调 `GameFlowController.BeginSimulation()`，确保 `Confirm / Analyze / Revenue` 用的是当前作物。
- `Simulation` 现在会保存选中的 `CropDef`：
  - `Evaluate` 用 `CropDef.Curves`（为空回退全局曲线）
  - `Revenue` 用 `CropDef.Yield`（为空回退 `SimConfig.Yield`）
  - `AnalyzeScreen` 的观测适宜度也用当前作物曲线
- **数值仍是占位**：文档 TABLE 1 没给甜菜/红薯/土豆的适宜度区间和 Ymax，所以四种作物暂时共用玉米的曲线与 `YmaxGeo=733`。等策划补数据后，只要给每种 `CropDef` 填自己的 `Curves` / `Yield`，不用改 UI 和流程。

## 2. 农场白膜

没有甜菜/红薯/土豆模型，所以：

- `corn`：继续用 9 个玉米 glb。
- 其他三种：用**白色胶囊**占位，按阶段变高（幼苗矮、成长/成熟高）。
- 换作物后 `FarmFieldBuilder` 会检测 `PlantTypeId` 变化，把之前按玉米建好的阶段作废并重建。
- 白膜不参与玉米的多材质合并；仍走 GPU Instancing。
- 之后拿到模型时，在 `ResolveCropPrefab` 里按 `CropId` 换成正式预制体即可。

## 3. UI 怎么生效

### Play 时（自动）

`GameFlowController.Awake` 会调用 `AllOptionsUi.Apply`：

- 找到 `Screen_LandSelect` / `Screen_PlantSelect`
- 四张卡的 `Button_Locked` 改成可用、文案「选择」
- 给按钮挂 `OptionCardButton`，填 Id / 显示名 / 目标界面
- 旧 `ScreenAction`（暂未开放 / GoTo LandParams）由 `PlaceholderScreen.Handle` 自动跳过

所以**即使不跑任何编辑器菜单，Play 时四张卡也能用**。

### 编辑模式也显示「选择」（可选）

菜单：**Tools ▸ UI ▸ 开放全部土地与植物**

- 调用同一份 `AllOptionsUi.Apply`
- 额外把旧的 `ScreenAction` 从 `PlaceholderScene.actions` 里删掉
- 保存 `UI.unity`

> 不要跑旧的「Tools ▸ UI ▸ 地形观察：应用 UI 补丁」——它会把卡片目标改成暂时不用的 `LandPreview`。本轮地形暂停，土地卡应直接进 `LandParams`。

## 5. 怎么验收

1. Play → 土地类型选择：四张卡都显示「选择」，都能点。
2. 分别选泽洼域/崇岭阶/高原坪 → 土地参数页 → 确认页第 1 行显示对应名称。
3. 植物类型选择：四张卡都显示「选择」，都能点。
4. 分别选甜菜/红薯/土豆 → 确认页第 2 行显示对应名称。
5. 进入农场：玉米仍是玉米；其他三种显示白色胶囊。
6. 收益页副标题显示「土地 x · 作物 y」。

已知限制：

- 四块地没有独立地形/初始土壤；四种作物共用玉米曲线和 Ymax。
- 非玉米是白膜，不是正式模型。
- `LandPreviewScreen` 仍是 UI 壳，没有地形；本轮不用它。
