## 一、手动巡航控制：找到并修掉了根因

### 原来的实现（有问题）

```csharp
// Q/E 转向
roverYaw += turn * turnSpeed * Time.deltaTime;

// WASD：把输入转到"相对当前朝向"
var h = Input.GetAxisRaw("Horizontal");
var v = Input.GetAxisRaw("Vertical");
var dir = Quaternion.Euler(0f, roverYaw, 0f) * new Vector3(h, 0, v);
rover.transform.position += dir * moveSpeed * dt;

// ★ 车头转向行进方向 —— 就是这一行出的问题
roverYaw = Mathf.LerpAngle(roverYaw, Mathf.Atan2(dir.x, dir.z) * Mathf.Rad2Deg, 0.25f);
```

### 三个具体问题

| # | 问题 | 后果 |
|---|---|---|
| 1 | **`LerpAngle` 每帧覆盖 Q/E 设的 yaw** | 你按住 E 转向的同时按 W，转向会被"车头对齐行进方向"这一步拽回去 —— 感觉"转不动" |
| 2 | **`A/D` 是横向平移，不是转向** | 按 A/D 车会**侧着滑**，同时车头又被 Lerp 转向侧向 → **车会转着圈跑**，非常怪 |
| 3 | `LerpAngle` 的 `0.25` 是**每帧系数**，不是每秒 | 帧率低时转得慢、帧率高时转得快，手感不稳定 |

### 修法：改成经典"车式操控"

```
Q / E  或  左/右方向键   →  转向（只由玩家控制，不再被覆盖）
W / S  或  上/下方向键   →  前进 / 后退
```

去掉了 `LerpAngle` 强转、去掉了 `Input.GetAxisRaw("Horizontal")` 横移。
**现在转向完全由玩家掌握**，不会自己被拽走。

## 二、自动巡航太慢：实测数据与修法

我按田块尺寸算了一下：

```
田块 27.3 × 21.3 m，扫描半径 3.0 m
车道间距 4.5 m → 5 条车道、10 个路点
总路程约 136 m
```

| 速度 | 耗时 |
|---:|---:|
| **4 m/s（原来）** | **34.1 秒** |
| 8 m/s | 17.0 秒 |
| **15 m/s（现在）** | **9.1 秒** |
| 30 m/s | 4.5 秒 |

**所以"很慢"是确实的 —— 34 秒，而且界面上没有任何进度提示，体验就是"卡住了"。**

### 修法

| 改动 | 说明 |
|---|---|
| **`autoSpeed` 4 → 15 m/s** | 全田从 34 秒降到约 9 秒 |
| 每到一个路点打印进度 | `自动巡航 3/10 路点，覆盖率 42.0%，预计还需 6 秒` |
| HUD 显示剩余时间 | 巡航界面显示`自动巡航中 40%　剩余约 6 秒` |
| **运行时加速** | `]` / `=` 加速，`[` / `-` 减速 |
| **`F` 一键最快** | 倍率直接拉到 ×8 |
| **`G` 立刻结束** | 把剩下的一次扫完，不用等 |
| 用 `MoveTowards` 代替 `+= dir*speed*dt` | 高速时**不会越过路点来回抖动** |

## 三、接下来验证「巡航探测闭环」

这是本项工作的核心。**完整链路：**

```
① 土地基础数据设置（填亩数 + 6 项）
      ↓ BeginSimulation
② 农场主界面（S1 只见土地）
      ↓ 点「巡航」
③ 机器人操控界面
      ↓ 点「手动巡航」或「自动巡航」
④ 切到农场场景，小车移动，覆盖率实时涨，未覆盖遮罩消失
      ↓ 覆盖率 ≥ 80%
⑤ 「更新数据」按钮变为可点 → 点击
      ↓ Flow.Back()
⑥ 农场主界面
      ↓ 点「分析」
⑦ 分析界面：显示适宜度 + 推荐方案
      ↓ 填水肥 → 「确认本阶段方案」
⑧ 提交成功 → 回农场，玉米进入下一阶段
      ↓ 重复 ③~⑧ 走完 S2 / S3 / S4
⑨ 收益界面
```

### 每一站要看什么

| 步骤 | 验证点 | 失败的典型表现 |
|---|---|---|
| ② | 农场里**只有土地**（S1 不显示植株） | 看到玉米 → `StageFromUiStage` 问题 |
| ④ | 覆盖率涨、遮罩消失 | 覆盖率一直是 0 → 网格/小车没接上 |
| ⑤ | 覆盖率 < 80% 时按钮**灰着** | 按钮一直可点 → 阈值没生效 |
| ⑦ | Console 有 `[Analyze] 探测值 vs 真值` 表 | 没有 → `FarmProbeState` 没传过来 |
| ⑧ | 玉米从幼苗 → 成长 → 成熟 | 阶段不变 → `FarmGrowthBinder` 问题 |
| ⑨ | 收益屏有数字 | 空白 → 收益没接内核 |

### 我预计最可能出问题的地方

前三项（`FarmProbeState` 传递、覆盖率阈值、阶段切换）都是**新写的、没跑过**的代码。
所以请**按上面的顺序走一遍**，每站把 Console 里对应的日志发我 ——
不需要你判断对错，有日志我就能定位。
