## 玩家体验

不再使用田里独立摆放的 FBX 小车。当前房车 GLB 中实际存在 `ROVER_ROOT` 小车和 `CTRL_ROBOT_RAMP` 机器人坡道，运行时将这辆嵌入的小车交给巡航载体驱动。原模型和源文件不修改。

每次手动/自动巡航：清空本轮采集 → 小车归舱、舱门关闭 → 镜头从当前农场视角平滑转向房车坡道侧斜上方 → 播放房车完整开舱动作并停在打开姿态 → 同一辆小车驶出坡道 → 镜头平滑回到原农场取景 → 小车开往巡航起点 → 启用手动驾驶或自动路线。

默认镜头转场1.2秒、开舱1.8秒、驶出2秒、返回镜头1.2秒、前往起点2秒，约8.2秒。开场期间不计算覆盖率，不接受驾驶及重复启动；HUD显示“房车正在打开机器人舱，小车出舱中”。离开巡航页会取消尚未完成的开场并释放镜头，小车归舱。巡航开始后返回农场仍沿用原有行为。

镜头返回农场总览，不再自动切为原有跟车视角；手动驾驶时相机不抢小车键盘输入。机器人跑完仍留在田里，下一轮巡航先归舱再演示出舱，目前不含自主返航入库过程。

## 编辑与参数

旧场景打开或重新加载脚本时，若找到房车自带小车，自动移除农场根节点下原来的独立 `Rover`（可通过Unity Undo撤销），场景标记未保存，Ctrl+S保存即可。运行时也兼容尚未保存迁移的旧场景：停用旧车，复用房车内小车。

FarmEquipment Inspector 中“巡航出舱镜头”可调整转场、开舱、驶出时间及打开姿态采样位置。当前GLB动画是 `AGRI_RV_Deployable`，6秒完整开关动作；采样到中段打开状态，完整片段可同步支撑杆等结构。不会再启动场景时循环开关；原片段可能同时展开车顶等部件。

缺失房车或ROVER_ROOT时仍兼容旧独立车巡航，不会因模型缺失阻断采集。

## 物理出舱替代位置插值

用户再次反馈下坡漂移后，出舱移动改成动态Rigidbody：35kg，ContinuousDynamic连续碰撞、重力、阻尼；机器人用模型本地包围盒生成简化BoxCollider。以AddForce推进水平速度，MoveRotation转向，不再通过Transform位置插值使小车沿预设高度移动；重力与碰撞决定垂直运动。

开舱动作完成后建立舱底、坡道内板/外板、门槛的MeshCollider接触面，避免舱门动画在刚体接触时快速运动把车弹飞。非种植区补充无渲染地面支撑；种植区GroundPad补BoxCollider。碰撞仅覆盖必要承托面，未给房车上千个零件或所有玉米加碰撞。

推进前检查脚下支撑；悬空时不给水平驱动力。出舱目标只约束水平位置，不写入目标高度，抵达后等待垂直速度稳定。出舱12秒、前往起点40秒保护超时；受阻时停止开场，不启动巡航、不补齐覆盖、不传送至目标点。重新开始仍使用既有归舱初始化；目前不是自主物理返航。

出舱完成/取消时停止刚体并转运动学，停用清理临时碰撞与物理材质，再将控制交还既有巡航器。**物理驱动范围是出舱和驶向巡航起点，后续手动/自动田间巡航仍使用原有控制方式。** 镜头代码未修改。

验证：编译0警告0错误。`PhysicsDepartureCheck` 使用Unity PhysX实际模拟，**8/8通过**：动态刚体与重力、碰撞体、重力下落后接触停止、物理力前进到目标、地面行驶不悬空、斜坡下降并落地、交接停止刚体、清理停用临时碰撞。日志 `Temp/departure-physics-check.log`。这批验证使用简化碰撞坡道，实际房车坡道的通过性、模型间隙和出舱速度仍需真实模型Play确认，不将简化测试当作实景验收。无Git提交或推送。


## 出舱后下陷与移动抖动修正

2026-10-16：用户确认出舱和镜头可用，但出舱后车轮陷土、移动抖动。核查发现物理支撑面高度0，与巡航GroundHeight所用土垄顶高不同；碰撞盒XYZ统一缩小10%使模型底部低于碰撞面；刚体交接后仍开启插值；MoveRotation每步用水平前向构建朝向，可能与坡面俯仰冲突。

修正：保留出舱接触面，在到巡航起点的路径上生成无渲染的连续支撑坡面连接垄顶高度，替代下方GroundPad碰撞承托；碰撞盒只缩水平尺寸，竖直尺寸保留模型底部；物理转向仅绕世界Y轴，不重置坡面俯仰；坡面驱动补偿沿坡重力，减少低速停滞；到达容差收紧到0.1m。交接关闭重力和刚体插值，转为运动学，并清除残留车身倾斜后交给巡航控制器。镜头未改。

验证：编译0警告0错误；Unity物理测试 **11/11通过**，新增带垄顶高度差的接地到达、交接插值/重力关闭、碰撞盒竖直尺寸保持。简化模型算例物理到达高度0.66m，巡航目标pivot高度约0.68m，差约0.02m。日志 `Temp/departure-ground-handoff-check.log`。支撑坡面是简化的接地通道，不是土壤逐三角形碰撞；真实田间车轮与视觉土垄贴合、画面抖动仍需主工程Play实测确认。未提交/推送Git。
