## 一、天空盒：有合适的，已配好

我实际看了 12 张的缩略图（`Temp/skybox_preview/skybox_contact_sheet.png`）：

| 编号 | 亮度 | 内容 | 适不适合 |
|---|---:|---|---|
| **sky-7** | 150 | **深蓝天空 + 白云 + 淡淡地平线雾** | ✅ **最适合**——白天的玉米田 |
| sky-1 | 166 | 大片云层，偏灰白 | ⭕ 可以，但天偏灰 |
| sky-11 | 174 | 过曝、发白，云层平淡 | ⭕ 太亮，对比弱 |
| sky-3 / sky-9 | 139 / 152 | 蓝天白云，云形夸张 | ⭕ 可以 |
| sky-4 | 123 | 蓝天 + 一朵孤立大云 | ❌ 那朵云太抢眼 |
| sky-8 | 87 | 地平线日出暖光 | ⭕ 黄昏氛围，不适合"白天农田" |
| sky-12 | 132 | 粉紫云层 + 橙地平线 | ❌ 火烧云，太戏剧化 |
| sky-2 / sky-5 | 66 / 62 | 暗红日落 | ❌ 不要 |
| sky-6 / sky-10 | 57 / 44 | 夜晚 / 深蓝月夜 | ❌ 不要 |

**结论：用 `sky-7`。已写进构建器**（`Assets/Art/8K Skybox Pack Free/Skyboxes/Material/sky-7.mat`）。

**一个用之前要知道的技术点**：

```
sky-7.png.meta:
  textureShape: 2          → 导入成 Cubemap（不是普通 2D 贴图）
  generateCubemap: 6       → 生成 6 面
  fileIDToRecycleName: 8900000: generatedCubemap
  maxTextureSize: 8192     → 8K cubemap
材质用的 shader: 内置 Skybox/Cubemap
```

也就是说**这包资源是拿来即用的**，材质已经指向生成好的 cubemap，不需要我做转换。

⚠️ **代价**：8K cubemap 显存占用不小（一个 8K RGBA cubemap 约 500 MB 未压缩，
压缩后仍很大）。桌面演示能跑，但如果后面要出 WebGL/移动端版本，**必须降到 2048**。
现在先不动。

**12 张一共 262 MB**，放在 `Assets/Art/` 下。**建议只保留 sky-7（或再加 1~2 张备选），
其余移出 `Assets`** —— 见第五节的风险提醒。

## 二、田块参数：我怎么定的

你定的规则是「**玩家选的亩数 = 块数，1 块 = 1 亩，实际尺寸与这无关**」。
我按这个把"块"实现成**玩法单位**，物理尺寸单独设计：

| 参数 | 取值 | 依据 |
|---|---|---|
| **单块土壤物理尺寸** | **4 m × 3 m**，垄面高 **0.475 m** | **实测 glb 包围盒**，不是我猜的（见下） |
| 每个"块"（1 亩）用几块土壤 | **3 × 3 = 9 块** | 让每个块都像一小片完整的田，而不是"4 株玉米" |
| 每个"块"的物理尺寸 | **12 m × 9 m** | 3×4 × 3×3 |
| 田块排列 | **2 × 2 = 4 块**（默认） | Demo 够看，玉米总数可控 |
| 整片田物理尺寸 | **约 26 m × 20 m** | 含 2 m 田埂间隔 |
| 玉米种植区 | 每块中心 **4 m × 4 m** | 留出边缘，看起来像垄间空地 |
| **株距** | **0.6 m** | 每块 7×7=49 株，全田 196 株 |
| 玉米总数 | **约 196 株** | 幼苗/成长/成熟各建一组，只显示当前阶段 |
| 随机化 | 每株随机偏航 ±25°、缩放 ±8% | 避免"复制粘贴感"；用确定性哈希，每次生成一致 |

**实测的模型尺寸（用 glb 的 accessor min/max 算的）**：

```
土壤块 玉米田土壤_四垄.glb :  4.000 × 0.475 × 3.000 m   最低点 y = 0
                            （垄面在 y = 0.475）
玉米    幼苗_正常          :  实测 0.36 m 高（说明文档一致）
        成长_正常          :  实测 1.30 m 高
        成熟_正常          :  实测 1.95 m 高
```

> 玉米 glb 的**整体包围盒是 2×2×2 居中原点**，被 110 个 `节环`/`雄穗花药`
> 单位球网格的半径撑大了 —— 那是建模时的辅助几何，实际植株比包围盒小得多。
> 所以**没有用包围盒来定位**，而是按 `说明.md` 标注的株高 + 土壤垄面高度来对齐。

**参数全部可改**，都在 `FarmFieldBuilder` 的 Inspector 里（`FarmVisualConfig`）：

```
田块列数 / 行数      → 改亩数（块数）
每个田块用几块土壤    → 改田的"厚度感"
株距                → 改玉米密度
玉米预制体根高度偏移  → Play 后如果玉米陷土/浮空，调这个
```

**改完不用重新搭场景** —— 运行时 `Build()` 会按新配置重建。

## 四、你需要在 Unity 里做的事

### 第 1 步：搭场景

```
菜单 Engineer / 农场 / 一键搭建农场场景
```

会生成并保存 `Assets/Scenes/Farm.unity`，里面有：
`Sun` / `FarmCamera` / `FarmRoot`（挂 `FarmFieldBuilder` + `FarmGrowthBinder`）/ `FieldCenter`。

**然后看 Console**：
- 如果报"没找到土壤块"或"有 N 个玉米模型没找到" → 说明 glb 路径变了，
  把对应的 glb 手动拖到 `FarmFieldBuilder` 的 `soilPiecePrefab` / `cornPrefabs` 上
- 如果一切正常，直接 Play（**单独跑 Farm 场景就能看到田和玉米**）

### 第 2 步：调三个观感参数

Play 之后大概率要微调这三个，都在 `FarmRoot` 的 `FarmFieldBuilder` 组件上：

| 现象 | 调哪个 |
|---|---|
| 玉米陷进土里 / 浮在空中 | `Config.CornBaseOffsetY`（米，正值上移） |
| 玉米太密 / 太稀 | `Config.CornSpacing`（0.6 是当前值） |
| 田太小 / 太大 | `Config.BlockColumns` / `BlockRows`（块数 = 亩数） |
| 相机看不全 | 菜单 `Engineer/农场/自动取景`，或直接拖相机 Transform |

### 第 3 步（可选）：把农场和 UI 合起来跑

现在 Farm 场景和 UI.unity 是**两个独立场景**。
`FarmGrowthBinder` 会自动在场景里找 `GameFlowController`，
所以**同场景并存**或**加性加载**都能工作。

三种做法，按成本排：

| 做法 | 成本 | 说明 |
|---|---|---|
| **A. 先各跑各的**（推荐先这样） | 0 | Farm 场景验证可视化；UI.unity 验证流程。互不影响 |
| B. 把 Farm 的内容拖进 UI.unity | 低 | 直接拖 `FarmRoot` / `Sun` / `FarmCamera` 过去。**注意 UI.unity 已有 Main Camera，会冲突** |
| C. 写一个 Bootstrap 场景做加性加载 | 中 | 最干净：Bootstrap 加载 `UI` + `Farm` 两个场景 |

**建议先 A**，确认画面没问题再考虑 B/C。
