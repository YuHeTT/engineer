## 二、误差模型（按你定的 5%~10%）

在 `FarmProbeState` 里：

```
amplitude = Lerp(10%, 5%, 覆盖率)          ← 扫得越多，误差越小，但永远 ≥5%
probe = truth × (1 + N(0, amplitude))       ← 多数指标用乘性
probe = truth + N(0, amplitude × truth)     ← pH 用加性（对数尺度乘性没意义）
```

**三个设计决定**：

1. **误差在"首次探测到该项"时固定**，不是每次刷新都变
   —— 用 `seed + index` 的确定性哈希。否则玩家会觉得数值在乱跳。
2. **覆盖率 100% 时仍有 5% 误差** —— 这样"探测"这一步永远有信息增益。
3. **探测值不写回数值内核**。内核里的土壤是权威数据（只能由水肥演算推进），
   探测值存在 `FarmProbeState` 里供界面和分析读。这样既有效果，又不污染内核。

## 三、覆盖率为什么用"面积法"而不是"数格子"

田块尺寸随亩数变化，和网格行列数不一定整除。
如果简单按"覆盖到格子中心就算整格已探测"，会**系统性高估**覆盖率
（边缘那半格没扫到却算 100%），而且误差随网格粗细变化，很难解释。

改成：先把整片田按 **10 像素/米**栅格化，每个像素归属它中心落入的格子，
算出每格的**真实面积**（只算一次并缓存）；探测时只把扫描半径内的部分计入。
于是 `覆盖率 = 已探测面积 / 田块总面积`，任何网格粗细下都自洽。

**实测**：27.3 × 21.3 m 的田，10 px/m 栅格约 5.8 万个采样点，一次性建好，巡航过程零开销。

## 四、怎么用（重要）

### 菜单顺序

```
1. Engineer / 农场 / 一键搭建农场场景      ← 生成 Farm.unity
2. Engineer / 农场 / 生成 Bootstrap 场景    ← 生成 Bootstrap.unity，并自动登记 Build Settings
3. 把 Bootstrap.unity 设为 Build Settings 的第 0 个场景
4. Play Bootstrap.unity
```

Bootstrap 会加性加载 `UI` + `Farm`，并**关掉 UI 场景的 Main Camera**（只留 FarmCamera），
避免两个相机互相覆盖。

### 按键

| 场景 | 按键 | 作用 |
|---|---|---|
| 农场相机 | `Tab` | 俯视 ↔ 第三人称 |
| | `C` | 取景档位循环：全景 → 中景 → 近景 |
| | `V` | 俯视角度：远景（带天空）↔ 纯俯视（看全局） |
| | `Q`/`E` | 旋转 |
| | 滚轮 | 缩放 |
| 巡航小车 | `WASD`/方向键 | 移动（手动巡航时） |
| | `Q`/`E` | 转向 |

### 玩法链路

```
进入农场 → 「巡航」→ RobotCruise 界面
   ↓ 点「手动巡航」或「自动巡航」
   ↓ 切回农场场景，小车开始动，走过的地方遮罩消失
   ↓ 覆盖率实时涨（界面读的是同一个 FarmFieldGrid）
覆盖率 ≥ 80% → 「更新数据」可点 → 回农场
   ↓
分析界面（后续接：探测值带误差）
```

**阈值**（在 `RobotCruiseScreen` 上可调）：

- `analyzeThreshold = 0.8` —— 到 80% 就能「更新数据」
- `completeThreshold = 1.0` —— 到 100% 算完整数据

## 五、多亩数联动

`FarmVisualConfig` 新增：

```csharp
public int BlockCount = 4;                    // 玩家选的亩数（= 块数）
public void ApplyBlockCount(int blocks);      // 自动拆成行列
public static readonly int[] SelectableBlockCounts = { 1, 2, 4, 6, 9, 12, 16 };
```

UI 那边玩家选了几亩之后：

```csharp
var cfg = fieldBuilder.Config;
cfg.ApplyBlockCount(selectedBlocks);
fieldBuilder.Build();
paths.Build();
terrain.Build();
grid.Build();
rig.FrameField(fieldBuilder.FieldBounds, cfg.BlockGroupSize.x);
```

**取景三档**（`FarmCameraRig.ViewLevel`）按"一个田块的宽度"定基准距离：

| 档 | 系数 | 用途 |
|---|---|---|
| `Panorama` | ×1.9 | 看整片田的户型、田埂、小路 |
| `Medium` | ×1.0 | 日常操作、看长势（**默认**） |
| `CloseUp` | ×0.32 | 贴近看单株，对比长势好坏 |

**注意**：`ApplyBlockCount` 之后一定要重跑 `FrameField`，否则相机还停在旧田块的位置。

## 九、修复记录：场景一片黑（2026-10-15）

### 现象

跑完「一键搭建农场场景」，Scene 视图里整片田是**深蓝黑色的一大块**，
比玉米范围大一圈，土壤和玉米都看不清。

### 排查：不是房车的问题

先排除房车 —— 房车在田块**外侧**（bearing 200°），
截图里它在左边、正常显示，不可能是它盖住田。

算一下遮罩的尺寸就确认了：

```
整片田（含田埂）= 27.0 × 21.0 m
网格 10 列 × 8 行   → 每格 2.70 × 2.62 m
未覆盖遮罩 = 80 个 Quad 铺满整片田，颜色 (0.05, 0.08, 0.12, a=0.55)
```

**遮罩铺满整片田，而玉米只占其中的种植区** —— 所以遮罩看起来"比玉米大一圈"，
和截图完全吻合。**就是未覆盖遮罩。**

### 三个原因

| # | 问题 | 后果 |
|---|---|---|
| 1 | **编辑器里也生成了遮罩** | 菜单一跑完，遮罩就铺在 Scene 里。做场景时完全看不出田和玉米长什么样 |
| 2 | **遮罩高度 1.6 m** | 幼苗只有 0.36 m 高，遮罩从**上面**盖住它 —— 看起来就是"玉米没了" |
| 3 | **alpha 0.55 太浓** | 连土壤材质都被压成一团黑 |

### 修法

| 改动 | 前 | 后 |
|---|---|---|
| 新增 `maskOnlyInPlayMode` | — | **默认开**：编辑器里不生成遮罩 |
| `maskHeight` | 1.6 m | **0.30 m**（贴地，低于垄面 0.475，不穿帮） |
| `maskColor.a` | 0.55 | **0.38** |
| `FarmSceneBuilder` | 建完网格就调 `RefreshMask()` | **不再调**（注释说明原因） |
| 新增菜单 | — | `Engineer/农场/切换未覆盖遮罩（编辑器预览）` |

### 现在的行为

- **编辑器里**：田、玉米、田埂、小路、地形、房车全部清晰可见，没有遮罩
- **Play 之后**：遮罩出现（贴地、较淡），小车扫过的地方遮罩消失
- 想临时看遮罩效果：用新增的那个菜单开关

### 顺带记一条经验

这是**第三次**"编辑器期生成的东西反过来干扰编辑器观察"（前两次是
`FarmFieldBuilder` 在编辑期生成 0 株玉米、相机 `FieldBounds` 为空）。
共用规律：**运行时的表现层组件，在编辑期要么不生成，要么显式关掉**。
