# 巡航相关逻辑全面审查与修复

> 日期：2026-10-15
> 你反馈：① 巡航时场景变纯灰色、看不到土地 ② 手动巡航键位和相机冲突、视角奇怪
> ③ 还有些说不清的问题，建议系统排查

## 一、纯灰色的根因：**相机与小车抢同一批按键** ★

这是本轮最关键的发现。我审查 `FarmCameraRig.HandleInput()` 发现：

```csharp
// 相机也在读 WASD
var h = Input.GetAxisRaw("Horizontal");
var v = Input.GetAxisRaw("Vertical");
if (Input.GetKey(KeyCode.Q)) yaw -= rotateSpeed * dt;
if (Input.GetKey(KeyCode.E)) yaw += rotateSpeed * dt;

// 而且在俯视模式下，WASD 会**平移观察中心**
if (mode == Mode.Overhead && (Mathf.Abs(h) > 0.01f || Mathf.Abs(v) > 0.01f))
{
    ...
    if (fieldCenter != null) fieldCenter.position += move;   // ★ 田块中心被推走
}
```

而 `FarmCruiseController` **也**在读同一批键：

```csharp
if (Input.GetKey(KeyCode.Q)) turn -= 1f;      // 转向
if (Input.GetKey(KeyCode.W)) forward += 1f;   // 前进
```

### 后果

| 你按 | 相机做 | 小车做 | 结果 |
|---|---|---|---|
| **`W`** | **把田块观察中心往前推** | 前进 | **田被推出画面 → 只剩地面和雾 → 纯灰色** |
| `Q`/`E` | 旋转相机 | 转向 | 两个都在转，方向感全乱 |
| `A`/`D` | 平移观察中心 | —— | 相机横向漂走 |

**"场景变纯灰色、看不到土地"就是这个** —— 相机被 WASD 推离了田块，
镜头对着远处的雾色地面，看起来就是一片灰。
（同理，"视角很奇怪"也是因为它同时被两套输入驱动。）

### 修法：**巡航期间相机完全让出输入**

| 改动 | 说明 |
|---|---|
| 新增 `FarmCruiseController.IsCruising` | 手动 / 自动巡航时为 true |
| `FarmCameraRig.HandleInput()` 开头加 | **`if (CruiseTakesInput) return;`** —— 巡航期间相机不接收任何键盘输入 |
| `CenterPoint()` | 巡航期间**看小车**，而不是田块中心 |
| `ComputePosition()` | 巡航期间用固定的"高 9 m + 后撤 11 m"跟车，而不是俯视参数（俯视距离是按"看全一个田块"算的，跟车会太远） |

**效果**：按 W 就是开车，相机会稳定地跟着车走，键盘只由小车使用。

## 二、顺带发现并修掉的两个漏洞

### 漏洞 1：未覆盖遮罩在**没巡航时就盖上**

`FarmFieldGrid.RefreshMask()` 原本只要"不在编辑期"就会把遮罩显示出来。
于是**一进农场就是一片深色遮罩**，田和玉米都看不清 ——
这和我之前修的"编辑器里不生成遮罩"是同一类问题，只是发生的时机不同。

**修法**：新增 `cruiseActive` 标志与 `BeginCruise()` / `EndCruise()`。
**只有开始巡航之后才显示遮罩**，巡航结束就撤掉。

### 漏洞 2：`RunInstantFallback`（没有 3D 场景时的兜底）没同步遮罩状态

已补：走兜底时也调 `BeginCruise → MarkAllScanned → EndCruise`，
保证状态一致，且不会留下一个盖住的遮罩。

## 四、一处需要你（或策划）确认的设计问题

### 跨阶段，覆盖率该不该重置？

现在的行为：**巡航一次，覆盖率保留到下一阶段**（因为 `OnEnter` 不再重置了）。

**这带来一个逻辑问题**：如果玩家在 S2 已经巡航到 100%，
那么到了 S3 一进巡航界面，覆盖率**还是 100%**，
于是"更新数据"按钮**一开始就是可点的** —— 玩家可以跳过 S3 的巡航。

**两种都说得通**：

| 方案 | 行为 | 适合的玩法 |
|---|---|---|
| **A. 每阶段重新巡航** | 进新阶段时覆盖率归零，必须重新探测 | 强调"每阶段都要下地探测" |
| **B. 一次巡航管到底** | 覆盖率跨阶段保留 | 强调"探一次就够"，流程更短 |

**我倾向 A**（每个生育期土壤状况会变，重新探测更符合"数字孪生"的设定），
但这需要策划定。**当前是 B 的行为。**

如果你想改成 A，改一处就行：在 `FarmGrowthBinder` 检测到阶段变化时调
`grid.ClearCoverage()`。**告诉我选哪个，我改。**
