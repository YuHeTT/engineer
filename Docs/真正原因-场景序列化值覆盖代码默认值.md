# 终于找到"改了代码却没有任何变化"的真正原因

> 日期：2026-10-15
> 你反馈：**没有任何改变，我不知道你改了什么**

你说得对 —— 而且**原因不在代码里，在场景文件里**。

---

## 一、根本原因：**序列化的旧值覆盖了我改的所有默认值**

Unity 的规则：

> `[SerializeField]` 字段的值**存在场景文件里**，运行时用场景里的值，
> **代码里的默认值只在"场景里没有这个字段"时才生效**。

我查了 `Farm.unity` 里 `FarmCruiseController` 的**实际存储值**：

```
    roverYawOffset: 0        ← 我改成 90，被场景的 0 覆盖
    moveSpeed: 5             ← 我改成 8，被场景的 5 覆盖
    turnSpeed: 120           ← 我改成 150，被覆盖
    autoSpeed: 4             ← 我改成 15，被覆盖（所以自动巡航一直是 34 秒！）
    waypointTolerance: 0.8   ← 我改成 1.0，被覆盖
```

**`Farm.unity` 从来没重新生成过** —— 它是很早以前建的，
里面存的是**当时的默认值**，一直盖住我后来所有的修改。

这解释了你反馈的**全部现象**：
- 朝向没变
- 自动巡航还是慢
- 其它优化没感觉

**不是代码没改对，是代码根本没被用上。**

---

## 二、比"旧值"更危险的一种情况：字段**缺失** → 反序列化成 0

我逐个检查了所有农场组件的场景值，发现 `FarmCameraRig` 里有三个字段
**在场景文件里根本不存在**（它们是后来才加进脚本的）：

```
   （场景里没有）cruiseFollowHeight
   （场景里没有）cruiseFollowBack
   （场景里没有）cruiseFollowPitch
```

**场景里没有的字段，Unity 会把它设成 0** —— 不是代码默认值！

后果是致命的：

```
cruiseFollowHeight = 0，cruiseFollowBack = 0
  → 跟车相机距离 = 0
  → 相机贴在车上（甚至钻进模型里）
  → 画面一片纯色 / 灰
```

**这正是你反复说的"巡航时车灰色"的另一个来源**（除了之前找到的影棚地面）。

### 顺带发现的三处

| 组件 | 场景值 | 代码默认 | 后果 |
|---|---|---|---|
| `FarmFieldGrid.maskColor.a` | **0.38** | 0.15 | 遮罩太浓 → 田发灰 |
| `FarmGrowthBinder.logSync` | **1** | 0 | 日志刷屏 |
| `FarmFieldBuilder.optimizeMeshes` | **0** | 1 | **网格没合并** → 性能优化没生效 |

## 三、我做的修复：直接改场景文件

因为 `Farm.unity` 只有 17 KB（几何都是运行时生成的），我直接改它的序列化值：

```
  FarmCruiseController.roverYawOffset    : 0   -> 90     ← 车头朝 Z
  FarmCruiseController.moveSpeed         : 5   -> 8
  FarmCruiseController.turnSpeed         : 120 -> 150
  FarmCruiseController.waypointTolerance : 0.8 -> 1
  FarmCruiseController.autoSpeed         : 4   -> 15     ← 自动巡航 34s → 9s
  FarmCameraRig 跟车字段                 : (缺失) -> 4.5 / 6 / 32 / 开
  FarmFieldGrid.maskColor.a              : 0.38 -> 0.15
  FarmGrowthBinder.logSync               : 1   -> 0
  FarmFieldBuilder.optimizeMeshes        : 0   -> 1
```

**备份**：`Farm.unity.bak_225039`、`Farm.unity.bak2_225102`

## 四、加了一道运行时守卫，防止再犯

在 `FarmCameraRig.Awake()` 里加 `SanitizeFollowParams()`：

```csharp
// [SerializeField] 字段如果在场景文件里不存在，Unity 会把它设成 0，
// 而不是代码默认值。后果：跟车距离 = 0 → 相机贴在车上 → 画面纯色。
if (cruiseFollowHeight <= 0.01f) { cruiseFollowHeight = 4.5f; fixedAny = true; }
if (cruiseFollowBack   <= 0.01f) { cruiseFollowBack   = 6f;   fixedAny = true; }
if (cruiseFollowPitch  <= 1f)    { cruiseFollowPitch  = 32f;  fixedAny = true; }
if (overheadHeight     <= 0.01f) { overheadHeight     = 22f;  fixedAny = true; }
if (overheadPitch      <= 1f)    { overheadPitch      = 20f;  fixedAny = true; }
```

一旦触发就打印警告，明确告诉是"字段缺失被反序列化成 0"。
**这样以后即使场景又过期，画面也不会变成纯色。**

## 五、我这次犯的错（如实记录）

| 错误 | 说明 |
|---|---|
| **改了代码默认值，却以为它会生效** | 完全忽略了 Unity 的序列化规则。**这是我这几轮反复失败的真正原因。** |
| 前四轮都在调 `roverYawOffset` 的值 | 那个值**从来没被用上**（场景里是 0，我改 0→90 的那个改的是代码默认值）|
| 没有第一时间去读场景里的实际值 | 应该一开始就查"场景里存的是什么"，而不是反复改代码 |

**教训**：在 Unity 里，**改 `[SerializeField]` 的代码默认值，对已存在的场景无效**。
要么改场景，要么重新生成场景，要么在运行时用代码强制覆盖。
